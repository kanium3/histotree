## About Histotree

View browser history as an interactive network graph powered by Sigma.js.

The popup groups recent history by site and connects sites that appear next to
each other in the browser history. Click a node to focus it, or double-click
to open the most recent page for that site.

## Installation

It is currently available from [GitHub Releases](https://github.com/kanium3/histotree/releases).
Firefox and Chromium-based browsers are supported. (It has been verified to work
on Firefox.)

## Settings

### Theme

You can choose from three themes: dark, light, and system.
The system theme is used by default.

### History Range

Specify the period for which history data should be loaded.
You can choose today, 7 days, 30 days, or 1 year.
The default is 7 days.

### Number of Sites

Specify the number of sites to load.
You can choose from 160, 300, 500, 700, or 1,000 sites.
The default is 160.

## Histotreeについて

ブラウザの履歴をグラフビューで見られる拡張機能です。線をたどることで、履歴のつながりを確認できます。

## インストール

現在は[GitHub Releases](https://github.com/kanium3/histotree/releases)からインストールできます。
FirefoxとChromium系ブラウザに対応しています。(Firefoxで動作確認済みです。)

## 設定

### テーマ

ダーク、ライト、システムの3種類から選択できます。
デフォルトではシステムのテーマに合わせます。

### 履歴表示期間

履歴データを読み込む期間を指定できます。
今日、7日間、30日間、1年間から選択できます。
デフォルトは7日間です。

### 読み込むサイト数

読み込むサイト数を指定できます。
160、300、500、700、1000件から選択できます。
デフォルトは160件です。
