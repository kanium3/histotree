## Project structure

There are some wxt's specilized folders, so see [Wxt](https://wxt.dev/llms.txt)

- `entrypoints/`: Webextension code

## Commands

- Start this webextension in firefox: `pnpm run dev:firefox`
- Run zipping: `pnpm run zip:firefox`
- Running lint: `pnpm run lint`
  - want to fix: `pnpm run lint:fix`
- Running format: `pnpm run fmt`
  - Should do it after making code changes
- Running test: `pnpm run test`
- Running type check: `pnpm run compile`
